# Life OS

Aplicación personal para organizar entrenamiento, salud y lesiones, deporte y finanzas.

## Tecnologías

- Web: Vue 3, TypeScript y Vite, con pnpm.
- Android: Kotlin, Jetpack Compose y Room, con funcionamiento sin conexión.
- API: Python y FastAPI.
- Persistencia: SQLite local y soporte opcional para PostgreSQL.

## Estado

Proyecto en desarrollo. El dashboard y el registro de entrenamiento cuentan con pruebas locales y recorridos de integración. El alojamiento previsto utiliza Vercel y Neon; el despliegue público y la publicación del código se están preparando.

Este commit inicial permite vincular el repositorio con los servicios de alojamiento. No contiene credenciales ni datos personales.
